# Release - Relocated checkout recovery - 0.8.2

Released 2026-09-18.

## Fixed

- The installer now recovers when a checkout has moved and the old absolute
  targets of `~/.local/bin/ahp` and `~/.local/bin/ahp-mcp` no longer exist.
  It repoints those broken AHP command links to the checkout from which the
  installer is running.
- Relative stale links are handled too: their target text is preserved long
  enough to identify the expected `bin/ahp` or `bin/ahp-mcp` entrypoint even
  though the old parent directory cannot be resolved.

## Safety boundary

- The repair applies only to a broken standard
  `agent-handoff-protocol/bin/<command>` link, or to a target confirmed as an
  AHP checkout through its `SPEC.md`. Existing real files, directories, live
  symlinks, and unidentifiable broken links remain untouched and produce an
  actionable installer warning.

## Recovery for an already-moved checkout

Run the updated installer from the new checkout:

```bash
./install.sh --mode mcp
```

The Command line and Self-test sections should both report a working `ahp`.
