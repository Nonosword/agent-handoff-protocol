# 0.5.12 — Event-driven dashboard watch

## Outcome

`ahp dashboard -w` now redraws in response to local AHP store filesystem
events. It no longer has a visible countdown or a periodic state-polling loop.

## Interface

- The product title **Agent Handoff** is rendered with the terminal bold style.
- The footer is concise again: `updated at HH:MM:SS`.
- The `-n` interval flag has been removed because watch is no longer paced by a
  refresh interval.

## Update model

The dashboard watches the local store tree. A worklog, Lane, or project-registry
change wakes the renderer immediately; it fingerprints and snapshots only after
that event. No network operation or Git `fetch` is involved, and unchanged rows
remain silent through the incremental renderer. Directory watchers re-arm after
tree changes so newly created Lane directories are also observed.
