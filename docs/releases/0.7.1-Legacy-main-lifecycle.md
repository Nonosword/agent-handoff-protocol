# Release - Legacy main lifecycle - 0.7.1

Released 2026-09-10.

## Legacy compatibility

- The synthetic `main / legacy` Lane now supports the same `active`, `done`,
  and `archived` transitions as named Lanes.
- Persisting its lifecycle status materializes only a metadata override in the
  Lane registry. Reads and writes continue to use the original project-wide
  worklog; no `lanes/main/worklog.jsonl` is created or selected.
- Its identity metadata remains fixed. The id, title, description, scope, and
  aliases cannot be edited, and a named Lane still cannot collide with `main`.
- Completion retains the 0.7.0 safety checks: baton free, no open intent, and a
  clean strict verification result.

## Verification

- `npm test`: 62 regressions passed.
- `npm run schema:check` and `npm run verify:examples` passed.
- Changed JavaScript modules passed `node --check`; the tree passed
  `git diff --check`.
