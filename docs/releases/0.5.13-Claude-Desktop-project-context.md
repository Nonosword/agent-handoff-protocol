# 0.5.13 — Claude Desktop project context

## Outcome

Project-scoped MCP tools now report a clear context error when their server is
started outside a Git checkout and the caller did not supply a project target.
This is the normal launch model for Claude Desktop's stdio MCP server; it is not
a Git-detection failure in the repository being discussed.

## Contract

- `cwd` is documented as an **absolute** directory inside the target checkout.
- A registered `project` id or name may be supplied instead of `cwd`.
- A relative cwd is rejected before it can resolve against the unrelated server
  startup directory.
- The missing-context error tells the MCP client to retry with the required
  target rather than saying only that the server is outside a repository.

After project selection, callers must also provide `lane` whenever that Project
has more than one Lane.
