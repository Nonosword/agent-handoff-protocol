# 0.5.10 — Dashboard zero countdown

## Outcome

`ahp dashboard -w` now displays the full countdown sequence, including zero:
`5`, `4`, `3`, `2`, `1`, `0`.

## Refresh timing

The zero footer is painted before the state fingerprint runs. It remains on
screen briefly so a terminal can present it, then the dashboard refreshes its
cached snapshot at that zero point and begins the next countdown. This replaces
the prior `1 → 5` jump.

The 100 ms zero-frame paint delay is only for terminal presentation. It keeps
the interval close to its configured duration while retaining the incremental
row renderer introduced in v0.5.9; no full-screen clear is performed.
