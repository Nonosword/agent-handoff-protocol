# 0.5.11 — Claude Desktop MCP registration

## Outcome

The installer now treats Claude Desktop and Claude Code as independent MCP
hosts. A Claude Code CLI installation is no longer a prerequisite for adding
the AHP server to Claude Desktop.

## Host-specific registration

- **Claude Code** continues to use `claude mcp add --scope user`; its
  CLI-managed configuration is not reused for Desktop.
- **Claude Desktop on macOS** is registered by a safe JSON merge into its own
  `~/Library/Application Support/Claude/claude_desktop_config.json` file.
- The Desktop entry runs `node <REPO>/bin/ahp-mcp` with a `claude-desktop`
  runtime marker. Other top-level settings and other MCP servers are preserved.
- `install.sh --uninstall` removes only `mcpServers.agent-handoff` from that
  Desktop file.

Quit and reopen Claude Desktop after registration: its MCP panel does not offer
an individual server reconnect control.
