# Release - Review integrity follow-up - 0.8.4

Released 2026-09-18.

## Failure-safe coordination

- AHP now removes only its own unpublished lock when writing or syncing that
  lock's token fails. This prevents an empty or truncated lock from blocking
  future Lane, Project-registry, Lane-registry, or installer MCP-config writes.
- A remote-less repository now rolls back the `ahp.project-id` it just minted if
  the central Project registration cannot be persisted. A failed first write no
  longer leaves an unexpected Git-local identity behind.

## Relocation-aware views

- The Dashboard and explicit `--project` Git-state commands prefer the checkout
  recorded as `lastSeenRoot`, after confirming it is still a Git repository.
  They fall back through older known roots only when necessary, so a still-present
  old copy does not mask the checkout that most recently wrote AHP state.

## Clear storage boundary

- English and Chinese user-facing documentation now state the exact boundary:
  AHP does not modify tracked files, the working tree, or Git history. A
  remote-less repository's first successful write stores only a private
  Git-local identity so directory moves retain their central worklog.
