# 0.5.9 — Incremental dashboard rendering

## Outcome

`ahp dashboard -w` no longer erases and redraws the entire alternate screen
once per second. This release replaces the full-frame watch renderer introduced
in 0.5.8 with an incremental, row-level renderer.

## Rendering behaviour

- The alternate screen is cleared only for the initial paint.
- Each later frame is compared with the preceding frame by row. Unchanged rows
  generate no terminal output.
- The countdown therefore repaints only the footer row each second. When a
  worklog changes, only its changed rows are erased and redrawn.
- A changed row is erased before its replacement is written, so shorter dynamic
  text cannot retain a stale suffix.

Raw/no-echo input handling remains in place: touchpad scroll escape sequences
are consumed, Ctrl-C exits the watch, and terminal mode is restored on exit.

## Compatibility

The watch still fingerprints project state only at the configured refresh
interval. The per-second heartbeat remains a local footer update and does not
add state scans or working-tree inspection.
