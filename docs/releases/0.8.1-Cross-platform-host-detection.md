# Release - Cross-platform host detection - 0.8.1

Released 2026-09-10.

## Claude Desktop

- The Desktop MCP config is resolved per platform: macOS keeps
  `~/Library/Application Support/Claude/claude_desktop_config.json`; elsewhere
  it is `${XDG_CONFIG_HOME:-~/.config}/Claude/claude_desktop_config.json`,
  Electron's `userData` directory for the app.
- A first-run install without a config file is identified by `/Applications/Claude.app`
  on macOS, or by `claude-desktop` on PATH / `/usr/lib/claude-desktop` on Linux.
- `CLAUDE_DESKTOP_MCP` and `CLAUDE_DESKTOP_APP` still override both.

## Codex and ChatGPT

- The Codex CLI, the ChatGPT desktop app and the `openai.chatgpt` IDE extension
  share one `~/.codex/config.toml`, so a single `codex mcp add` registration
  covers all of them. The installer reports each surface separately.
- The codex binary used for registration and uninstall is resolved in order:
  `codex` on PATH, the binary bundled with the ChatGPT (or legacy Codex) desktop
  app, then the binary bundled with the newest installed IDE extension in VS
  Code, Insiders, VS Code Server, Cursor or Windsurf. A candidate must answer
  `--version` before it is used.
- When a Codex surface is present but no usable binary is found, the installer
  prints the `config.toml` entry to add by hand.
- `CHATGPT_APP` and `CODEX_CLI` override discovery. The Linux ChatGPT app
  locations (`/opt/ChatGPT`, `/opt/chatgpt`, `/usr/lib/chatgpt`, or the target
  of `chatgpt` on PATH) are inferred from its preview packaging.
