# 0.5.8 — Dashboard watch terminal resilience

## Outcome

`ahp dashboard -w` now remains visibly alive and resilient to touchpad scroll
input in an interactive terminal.

## Terminal behaviour

- While watch is active, stdin enters raw/no-echo mode and consumes ordinary
  terminal input. Arrow-key escape sequences emitted by touchpad scrolling no
  longer appear as literal `^[[A` / `^[[B` text in the dashboard.
- Raw mode handles Ctrl-C directly and is restored, along with the cursor and
  alternate screen, when the watch exits.
- Every rendered frame now clears the complete screen before rendering. A
  shorter or changed frame cannot leave old record rows or text suffixes such
  as `agoow` / `freedex` behind.

## Refresh visibility and cost

The footer now shows `refresh in 5s`, `4s`, `3s`, `2s`, `1s` (or the selected
`-n` interval). It redraws this cached frame once per second, so the operator
can tell watch is alive even when no worklog changes.

State polling remains bounded by `-n`: worklog metadata, Lane metadata, and
the cheap Git head view are fingerprinted only when the countdown reaches zero.
The per-second countdown does not add full snapshot or working-tree scans.
