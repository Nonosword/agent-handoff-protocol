# Release - Review remediation - 0.6.0

Released 2026-09-10.

## Integrity and routing

- Project registration no longer silently joins different remotes merely because
  their readable slugs collide. Existing ids remain compatible; a deterministic
  suffix is allocated only for a conflicting new remote.
- A command resolved with `--cwd` uses that checkout for Git state, rather than
  the first historical checkout recorded for the Project.
- Appending now rejects protocol-invalid records before bytes are written and
  repairs the missing separator of a valid final JSONL line. Lock recovery does
  not reclaim an empty/initializing lock.
- Archiving a Lane holds its worklog lock while checking baton state and writers
  re-check archived status under their write lock.

## Hosts and MCP

- TOML shell-environment surgery accepts standard comments and literal strings,
  and defers unsupported target syntax rather than creating duplicate keys.
- Uninstall removes JSON shell identity values only when they still equal the
  values installed by AHP; later user customizations are retained.
- MCP accepts the documented `AHP_PROJECT` context when a desktop server starts
  outside a Git checkout.

## Dashboard

- `dashboard -w` remains filesystem-event-driven. It has no relative-time
  repaint loop; Lane events and the footer use fixed local timestamps.
- The normal display uses the Lane title once, hides zero open intents, and
  keeps the baton indicator independent from a positive open-intent count.
- Store watcher shutdown, missing-store startup, event bursts, terminal width,
  and terminal height are handled explicitly to avoid stale or wrapped frames.

## Verification

- `npm test`: 59 end-to-end and module regressions passed.
- `npm run schema:check` and `npm run verify:examples` passed.
