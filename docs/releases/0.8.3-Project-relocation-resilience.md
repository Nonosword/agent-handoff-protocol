# Release - Project relocation resilience - 0.8.3

Released 2026-09-18.

## Stable external-store identity

- Remote-backed Projects continue to use the normalized `origin` remote. The
  first AHP write from a moved checkout records that new root and last-seen
  location in the central registry; reads make no registry mutation.
- Remote-less Git Projects now mint `ahp.project-id` in Git local config on the
  first write. It is a random local identity, not a tracked file or Git-history
  change, and survives moving the checkout.

## Boundary

- Worklogs, Lanes, batons and archives remain exclusively in the central AHP
  store. This release deliberately does not add a repo-local `.ahp` database,
  avoiding divergent worktree state and preserving Dashboard operation outside
  a checkout.
