# 0.4.2 — Neutral dashboard subtle colour

Released 2026-09-07.

## Outcome

- All auxiliary dashboard text now uses one `subtle` colour token: neutral ANSI-256 grey `38;5;250`.
- This avoids Tabby `90` / bright-black being substantially darker than macOS Terminal while retaining a consistent hierarchy.
- Separator rules remain an independent ANSI `90` `rule` token, so they stay visually quieter than information-bearing auxiliary text.
- The free-baton icon uses the same `subtle` colour as its label.

## Verification

- `npm test` — 35 passed, 0 failed.
- `npm run verify:examples` — all three bundled worklogs passed.
- The colour-token unit test proves that both Apple Terminal and Tabby environments receive the same auxiliary and separator palette.
