## Lifecycle scenarios

- A held Lane cannot become `done` or `archived`.
- A free Lane with an open intent cannot become complete.
- A free Lane whose worklog fails strict verification cannot become complete.
- Done Lanes appear in default CLI/MCP discovery and remain readable.
- An implicit start does not reopen a done Lane; explicit `start --lane` does.
- Archived Lanes disappear from default lists and Dashboard JSON, reappear with
  `--all` / `all:true`, reject start, and can be explicitly unarchived.
- Dashboard human output hides done Lane detail behind a compact count while
  active Lane rendering remains unchanged.
- Historical `blocked` metadata remains readable, rejects new worklog writes,
  and can be migrated back to a supported status.
