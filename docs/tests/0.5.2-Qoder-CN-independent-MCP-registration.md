# 0.5.2 — Qoder CN installer test result

## Isolated regression

The Node test creates a temporary HOME containing only a Qoder CN config and a
fake `qoder-cn` 1.28.0 CLI. `install.sh --mode mcp --dry-run --no-color` must:

- report `qoder` as not found and `qoder cn` as detected;
- show the CN `--add-mcp <JSON>` registration command; and
- omit every normal Qoder `mcp add` registration command.

## Real local dry run

The installed CLI at
`/Applications/Qoder CN IDE.app/Contents/Resources/app/bin/qoder-cn` reported
version 1.28.0. The installer reported ordinary Qoder absent, Qoder CN present,
and planned only that CLI's `--add-mcp <JSON>` call. SHA-256 before/after checks
confirmed that `~/.qoder-cn/mcp.json` was unchanged during dry run.

## Gate result

- `npm test`: 43 passed, 0 failed.
- `bash -n install.sh`: passed.
- `npm run verify:examples`: passed (all bundled examples validate; expected interrupted-session notes remain non-fatal).
