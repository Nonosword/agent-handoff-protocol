# 0.5.14 — Per-host worker identity test result

## Regression coverage

Two isolated installer tests, each running `install.sh` against a seeded `HOME`:

- **identity wiring** — seeds `~/.claude/settings.json` (`theme`, `env.FOO`) and
  `~/.codex/config.toml` (an existing `[shell_environment_policy.set]` with an
  unrelated key, plus an `[mcp_servers.other]` table). After `--mode cli`:
  `settings.json` gains `env.AHP_WORKER_ID/_MODEL/_RUNTIME` while `theme` and
  `env.FOO` survive; `config.toml` gains the three keys directly under the set
  table with the unrelated key and the rest of the file intact, and
  `config.toml.ahp.bak` exists. A second run reports "current" and rewrites
  nothing. `--uninstall` restores `settings.json` by deep-equal and
  `config.toml` byte-for-byte.
- **table shapes** — a Codex config with no `[shell_environment_policy…]` table
  gets one appended at EOF; a config whose `[shell_environment_policy]` uses an
  inline `set = { … }` is left untouched and the installer prints the
  add-by-hand snippet.
