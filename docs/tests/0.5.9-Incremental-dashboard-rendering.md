# 0.5.9 — Incremental dashboard rendering test result

## Regression coverage

The dashboard renderer is exercised directly with a capture output stream:

- its initial paint clears the fresh alternate screen exactly once;
- an identical next frame emits no terminal bytes;
- a changed row emits only a cursor move, line erase, and replacement text.
- removing a formerly populated row emits a line erase, preventing stale text
  from being left behind.

The source-level regression checks retain raw/no-echo input, the countdown,
bounded polling, and the lightweight Git head fingerprint.
