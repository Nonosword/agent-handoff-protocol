# 0.5.3 — Worklog integrity test result

## Regression scenarios

- A long-lived open intent is created in an old completed session, followed by
  three newer completed sessions. `compact --keep 2` retains the old session
  instead of moving its lone `intent.open` to the start of the live worklog.
  `ahp verify` remains successful.
- A later-session promotion retains its old `intent.open` source record when
  that promotion falls in the live suffix.
- Invalid `--keep 0` is rejected before any compaction write.
- Hand-edited records with an invalid worker, `continuesFrom`, state object, or
  plan are rejected by `validateRecords()`.
- A foreign worker ending a baton and an earlier non-pass end without findings
  remain errors even when a later pass end follows.

## Gate result

- `npm test`: 46 passed, 0 failed.
- `npm run verify:examples`: all bundled examples validate; the documented
  hard-cutoff note remains non-fatal.
- `npm run schema:check`: not run to a passing result because the repository
  does not yet declare the optional AJV development dependencies. This is the
  known schema-check reproducibility follow-up, outside this release's runtime
  dependency boundary.
